# akv-preflight

Read-only readiness check for installing akvorado-platform on RHEL 9. It installs, changes and deletes nothing and never prints a credential.
This repository is temporary and contains only the script `p` (source: a private repository, commit de1cd6e9d546).

    curl -sS -H Accept:application/vnd.github.raw https://api.github.com/repos/jaber717/akv-preflight/contents/p|bash
